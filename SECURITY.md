## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

- Open a [private security advisory](../../security/advisories/new) on GitHub.
- Alternatively, email us at **taplatero@outlook.es**.
- We aim to respond within **72 hours** and resolve validated issues within **7 days**.

Please provide as much detail as possible in your report, including:
- A clear description of the vulnerability.
- Steps to reproduce (if applicable).
- Potential impact or affected components.

Your report will be reviewed and handled confidentially. Thank you for helping us keep this project secure.
